## 1. Building a working 3D printer (2018-2019)

Complete construction of a 3D printer, from mechanical design to electronic assembly.

### Features
- **Structure**: mostly made of wood, entirely designed and thought out by myself (no pre-existing plans).
- **Electronics**: components bought individually online
  - NEMA 17 stepper motors
  - Arduino MEGA board + RepRap shield
  - Printing nozzle 
  - Other necessary components (motor driver, end stops,...)
- **Firmware**: [Marlin](https://marlingfw.org/) *(open source firmware)*, flashed onto the Arduino Mega paired with the RepRap shield.

### Result
The machine was fully functional and able to print, even though the print quality remained improvable (homemade calibration obliges!).

Hobby project with no particular practical application, made to explore articulated robotics.

### Features
- Parts produced using the 3D printer built previously.
- Reuse of leftover motors + addition of servomotors and other components.

## 3. "Drone-Bricks" project (2020)

Concept of mini-drones whose 3D-printed frame is designed to link with other units in order to form modular structures.

### Features
- Frame entirely 3D-printed, designed for modular assembly between several drones.
- Only one unit was built and tested.
- Project abandoned before going further in the development of the modular system.
